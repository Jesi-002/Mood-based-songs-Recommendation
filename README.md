Project Report
Project Title

Mood Based Music Recommendation System

 Synopsis:

The Mood Based Music Recommendation System is a C programming project that recommends songs according to the user's mood. It allows users to add songs, search for songs, rate songs and manage favourite songs. The project provides a simple menu driven interface and demonstrates the use of basic C programming concepts.

Description:

The Mood Based Music Recommendation System is designed to help users find and manage songs based on different moods such as Happy, Sad, Relaxed, fun, funky and Energetic. The program stores song titles, moods, ratings and favourite status using arrays.

Users can add new songs, view all songs, search for a specific song and receive recommendations by entering a mood. The system also allows users to add or remove songs from their favourites and update song ratings. It can display the available moods without repeating the same mood.

The project is developed using basic C programming concepts such as arrays, functions, strings, loops, conditional statements, searching, input from users and pointers. Different functions are used for different operations for making the program organized and easy to understand.

Features:

* Add new songs with mood and rating.
* Display all songs and their ratings.
* Recommend songs based on mood.
* Search for a specific song.
* Add songs to favorites.
* Display and remove favorite songs.
* Change song ratings from 1 to 5.
* Display available moods without duplicates.

 Challenges Faced:

* Managing song and mood information using arrays.
* Working with 2D character arrays.
* Using strcmp() for comparing song names and moods.
* Managing favourite songs using an integer array.
* Validating song numbers and ratings.
* Avoiding duplicate moods when displaying moods.
* Dividing the program into multiple functions and connecting them correctly.
